# H27 Group

## Overview

This is the group of HTTP APIs between the
**Partner Portal (Admin Telcenter Partner & Partner Staff)**
and [**Partner Employee Identity Service – S10**](../services/partner/S10_Partner_Employee_Identity_Service.md).

This API group supports the following use cases:

* **TP-01: Partner Login**
* **TP-02: Add Partner Employee Account**
* **TP-03: Update Partner Employee Account**
* **TP-04: Delete / Disable Partner Employee Account**

The APIs are designed following RESTful principles and used for **authentication and management of Partner employee accounts**.

---

## H27 Endpoint 1: `POST /api/v1/partner-auth/login`

(**Use Case: TP-01 – Partner Login**)

This endpoint allows **all Partner actors** to log into the Telcenter Partner Admin Portal.

### Actor

All Partner actors (Admin / Staff)

### Trigger

Open Partner Admin Portal.

### Preconditions

* A valid Partner account already exists.

### Postconditions

* Login is successful.
* The system returns a JWT token.
* The user is redirected to the Partner Dashboard.

### Request

**Headers**

```
Content-Type: application/json
```

**Body**

```json
{
  "username": "partner_admin",
  "password": "Partner@123"
}
```

### Behavior

1. The user enters username and password.
2. The system validates the credentials.
3. If valid, a JWT access token is generated.
4. The system redirects the user to the dashboard.
5. If login fails **≥ 5 times**, the account is locked for **30 minutes**.

### Alternative Flow

* User selects **“Quên mật khẩu”** → enters email → receives password reset link.

### Response (HTTP 200 OK)

```json
{
  "status": "success",
  "message": "Đăng nhập đối tác thành công",
  "access_token": "<jwt_token>",
  "token_type": "Bearer",
  "expires_in": 3600,
  "partner_employee": {
    "employee_id": 101,
    "full_name": "Nguyễn Văn Partner",
    "role": "ADMIN",
    "status": "ACTIVE"
  }
}
```

### Error Responses

* **HTTP 401 Unauthorized – Invalid credentials**

```json
{
  "status": "error",
  "error_code": "INVALID_CREDENTIALS",
  "message": "Sai tên đăng nhập hoặc mật khẩu"
}
```

* **HTTP 403 Forbidden – Account locked**

```json
{
  "status": "error",
  "error_code": "ACCOUNT_LOCKED",
  "message": "Tài khoản bị khóa do đăng nhập sai nhiều lần"
}
```

## H27 Endpoint 2: `GET /api/v1/partner-employees`

(**Use Case: TP-05 – Get All Partner Employees**)

This endpoint allows **Partner Admin** to retrieve a paginated list of all partner employees.

### Actor

Admin Telcenter Partner

### Trigger

Navigate to Partner Employee Management page.

### Preconditions

* Admin is logged in.
* Admin has sufficient permission.

### Postconditions

* A list of partner employees is returned with pagination info.

### Request

**Headers**

```
Authorization: Bearer <jwt_token>
```

**Query Parameters**

| Parameter | Type   | Required | Default | Description                    |
| --------- | ------ | -------- | ------- | ------------------------------ |
| page      | int    | No       | 1       | Page number                    |
| limit     | int    | No       | 10      | Number of items per page       |
| status    | string | No       | -       | Filter by status (ACTIVE, etc) |

### Behavior

1. Validate Admin authentication and permission.
2. Query employees from database with pagination.
3. For each employee, include role name.
4. Return paginated results.

### Response (HTTP 200 OK)

```json
{
  "status": "success",
  "data": {
    "employees": [
      {
        "_id": "507f1f77bcf86cd799439011",
        "full_name": "Nguyễn Văn A",
        "email": "nva@partner.vn",
        "role_id": "507f191e810c19729de860ea",
        "role_name": "Partner Admin",
        "status": "ACTIVE",
        "failed_login_attempts": 0,
        "locked_until": null
      },
      {
        "_id": "507f1f77bcf86cd799439012",
        "full_name": "Trần Thị B",
        "email": "ttb@partner.vn",
        "role_id": "507f191e810c19729de860eb",
        "role_name": "Partner Staff",
        "status": "ACTIVE",
        "failed_login_attempts": 0,
        "locked_until": null
      }
    ],
    "total": 25,
    "page": 1,
    "limit": 10,
    "total_pages5: 3
  }
}
```

### Error Response

* **HTTP 401 Unauthorized – Invalid or missing token**

```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Token không hợp lệ"
}
```

## H27 Endpoint 3: `GET /api/v1/partner-employees/{employee_id}`

(**Use Case: TP-06 – Get Partner Employee Detail**)

This endpoint allows **Partner Admin** to retrieve detailed information about a specific employee, including their role and permissions.

### Actor

Admin Telcenter Partner

### Trigger

Click on an employee row to view details.

### Preconditions

* Admin is authenticated.
* Employee account exists.

### Postconditions

* Detailed employee information is returned, including role and permissions.

### Request

**Headers**

```
Authorization: Bearer <jwt_token>
```

**Path Parameters**

| Parameter   | Type   | Required | Description           |
| ----------- | ------ | -------- | --------------------- |
| employee_id | string | Yes      | The employee ObjectId |

### Behavior

1. Validate Admin authentication and permission.
2. Query employee by ID from database.
3. Retrieve associated role information with permissions.
4. Return comple6e employee details.

### Response (HTTP 200 OK)

```json
{
  "status": "success",
  "employee": {
    "_id": "507f1f77bcf86cd799439011",
    "full_name": "Nguyễn Văn A",
    "email": "nva@partner.vn",
    "status": "ACTIVE",
    "failed_login_attempts": 0,
    "locked_until": null,
    "role": {
      "id": "507f191e810c19729de860ea",
      "name": "Partner Admin",
      "permissions": [
        "employee:create",
        "employee:read",
        "employee:update",
        "employee:delete",
        "conversation:read",
        "conversation:manage"
      ]
    }
  }
}
```

### Error Responses

* **HTTP 400 Bad Request – Invalid employee ID**

```json
{
  "status": "error",

  "message": "Employee ID không hợp lệ"

  "message": "Không tìm thấy nhân viên"
}
```

* **HTTP 401 Unauthorized – Invalid or missing token**

```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Token không hợp lệ"
}
```

## H27 Endpoint 4: `POST /api/v1/partner-employees`

(**Use Case: TP-02 – Add Partner Employee Account**)

This endpoint is used by **Partner Admin** to create a new employee account.

### Actor

Admin Telcenter Partner

### Trigger

Click **“Thêm mới”** in Partner Account Management.

### Preconditions

* Admin is logged in.
* Admin has sufficient permission.

### Postconditions

* A new Partner employee account is created.
* A default password is generated.
* An activation email is sent.

### Request

**Headers**

```
Authorization: Bearer <jwt_token>
Content-Type: application/json
```

**Body**

```json
{
  "full_name": "Trần Văn C",
  "email": "partner.staff01@partner.vn",
  "role_id": 2
}
```

### Behavior

1. Validate Admin permission.
2. Validate input information.
3. Check duplicate email.
4. Create a new employee account with default password.
5. Set account status to **INACTIVE**.
6. Send activation email.

### Response (HTTP 201 Created)

```json
{
  "status": "success",
  "employee_id": 205,
  "message": "Tạo tài khoản nhân viên đối tác thành công và đã gửi email kích hoạt"
}
```

### Error Response

* **HTTP 409 Conflict – Email already exists**

```json
{
  "status": "error",
  "error_code": "EMAIL_ALREADY_EXISTS",
  "message": "Email đã tồn tại"
}
```

## H27 Endpoint 4: `DELETE /api/v1/partner-employees/{employee_id}`

(**Use Case: TP-04 – Delete / Disable Partner Employee Account**)

This endpoint allows **Partner Admin** to disable or temporarily lock an employee account.

### Actor

Admin Telcenter Partner

### Trigger

Click **“Xóa”** on an employee row.

### Preconditions

* Admin is authenticated.
* Employee account exists.

### Postconditions

* The employee account is disabled or locked.

### Request

**Headers**

```
Authorization: Bearer <jwt_token>
```

**Optional Query Param**

```
?lock_only=true
```

### Behavior

* Default action: **disable (soft-delete)** the account.
* Alternative flow: If `lock_only=true`, the account is **temporarily locked**.

### Response (HTTP 200 OK)

```json
{
  "status": "success",
  "message": "Tài khoản nhân viên đối tác đã bị vô hiệu hóa"
}
```

## Configuration

Base URL is configurable via `.env`:

```
PARTNER_IDENTITY_SERVICE_URL=http://localhost:7010
```

---

## Notes

* All endpoints except **login** require **JWT authentication**.
* **JWT tokens** are required for all authenticated requests and MUST be signed using the RS256 algorithm. Valid tokens MUST be generated in accordance with [the JWT signing workflow](../auth/SIGN.md).
* Only users with role **PARTNER_ADMIN** are allowed to manage employee accounts.
* **5 failed login attempts → lock account for 30 minutes**.
* New employee accounts require **email activation**.
* Delete operation is **soft-delete by default**.
* Rate limiting: **60 requests/minute per admin**.
* CORS is enabled for Partner Portal domain.
* All Partner account actions are logged for **audit & security**.
